# AI Workforce Intelligence System

An end-to-end Machine Learning project that predicts employee burnout rate using workforce-related features.

## Features
- Employee burnout prediction
- Machine learning pipeline
- Data preprocessing and feature engineering
- Streamlit web application
- Burnout risk categorization

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

## How to Run Locally

1. Clone repository

```bash
git clone YOUR_REPOSITORY_LINK
```

2. Navigate to project folder

```bash
cd AI_Workforce_Intelligence_System
```

3. Activate virtual environment

```bash
venv\Scripts\activate
```

4. Install dependencies

```bash
pip install -r requirements.txt
```

5. Run Streamlit app

```bash
streamlit run app/app.py
```
